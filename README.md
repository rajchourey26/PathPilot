# 🚀 PathPilot

> AI-powered productivity assistant that transforms overwhelming goals into personalized, actionable plans using Google Gemini AI.

---

## 📌 Problem Statement

**The Last-Minute Life Saver**

Students, professionals, and entrepreneurs often struggle with overwhelming workloads, unclear priorities, and limited time before important deadlines. PathPilot helps users quickly convert complex goals into structured, achievable action plans.

---

## 💡 Solution

PathPilot is an AI-powered productivity assistant that helps users transform overwhelming goals into realistic execution plans.

Using Google's Gemini API, it analyzes the user's goal, available time, and deadline to generate:

- Prioritized tasks
- Smart scheduling
- Time-boxed execution plans
- Immediate next actions
- Progress tracking

Instead of overwhelming users with large to-do lists, PathPilot focuses on what matters most so users can make meaningful progress before their deadline.
---

## ✨ Features

- 🎯 AI-generated personalized action plans

- 📋 Priority-based task organization

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/rajchourey26/PathPilot.git
```

### 2. Open the project

```bash
cd PathPilot
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file using `.env.example`.

Example:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### 5. Start the project

```bash
npm run dev
```
